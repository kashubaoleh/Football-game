FOOTBALL LEAGUE - структура проєкту
====================================

ПАПКИ (кожен шар знає лише про нижчі)
  core/        модель даних: Team (зі складом), Match, MatchLog, Config
  sim/         Random (єдиний генератор із seed) і MatchSimulator
  tournament/  жеребкування, таблиця, плей-оф і Tournament (весь стан і хід турніру).
               Нічого не виводить у консоль - можна тестувати без неї.
  io/          завантаження команд і складів із файлу, пошук файлів
  ui/          усе, що бачить гравець: меню (GameEngine), екрани, трансляція, консоль
  tools/       масова симуляція для перевірки балансу
  data/        teams.txt - команди (поза кодом)
  main.cpp     точка входу

ЯК ПЕРЕНЕСТИ В CODE::BLOCKS
  1. Розпакуйте архів у теку проєкту (поруч із .cbp).
  2. Видаліть зі старого проєкту (Remove files from project) і з диска старі плоскі файли:
     Config.h, GameEngine.h, GameEngine.cpp, GameEngineFlow.cpp, LeagueDraw.h/.cpp,
     LeagueTable.h/.cpp, Match.h, MatchLog.h, MatchSimulator.h/.cpp,
     PlayoffManager.h/.cpp, Team.h (main.cpp замінюється новим).
  3. Project -> Add files recursively... -> оберіть теку проєкту -> залиште .cpp і .h
     (data/teams.txt додавати не треба).
  4. Шляхи пошуку заголовків налаштовувати не потрібно: підключення відносні.
  5. Усі .cpp і .h збережені в Windows-1251, як і раніше.

КОМАНДИ І СКЛАДИ (data/teams.txt)
  Рядок команди:   Назва ; атака ; захист
  Рядок гравця (під своєю командою):   ПОЗИЦІЯ  Ім'я
     Позиція: GK, DF, MF, FW або слова воротар, захисник, півзахисник, нападник.
  Вимоги: рівно 36 команд; у кожної рівно 11 гравців, з них один воротар;
  імена в межах команди не повторюються. Схема команди довільна (4-3-3, 3-5-2 ...).
  Перші 9 команд - корзина 1, наступні 9 - корзина 2 і так далі.
  Номер команди в списку (1-36) є її початковим рейтингом (5-те правило таблиці).
  Порожні рядки й рядки з # ігноруються. Файл можна зберігати в UTF-8 або Windows-1251.
  Якщо щось не так, програма покаже ВСІ помилки одразу з номерами рядків.
  Файл шукається в data/ або поруч, у поточній теці, у теці програми та на 3 рівні вище.

ХТО ЗАБИВАЄ
  Автор кожного гола обирається випадково з урахуванням позиції: нападники забивають
  найчастіше, потім півзахисники, потім захисники, воротарі не забивають.
  Ваги налаштовуються в core/Config.h (SCORER_WEIGHT_*). Для 4-3-3 це приблизно
  59% / 29% / 12% голів. Автори обираються окремим потоком випадкових чисел, тому
  рахунок і хвилини голів з тим самим seed не змінюються.

ПАРАМЕТРИ ЗАПУСКУ (необов'язкові; Code::Blocks: Project -> Set programs' arguments)
  --seed N     відновити турнір із цим seed (N від 0 до 4294967295).
               Seed поточного турніру видно в головному меню.
  --batch N    не грати, а прогнати N турнірів і показати статистику
               (разом із --seed результат відтворюється).

SEED
  Seed повністю визначає турнір: жеребкування та результат кожного матчу.
  Результат не залежить від того, як ви проходите турнір (промотка, ручні матчі,
  трансляція). Наступний турнір отримує наступний seed у ланцюжку; щоб відновити
  його, запустіть гру з --seed, який було показано в меню.
