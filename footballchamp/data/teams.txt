# Команди турніру та їхні стартові склади.
#
# РЯДОК КОМАНДИ:   Назва команди ; атака ; захист
#   Атака й захист - числа більше 0 (десяткова крапка або кома).
# РЯДОК ГРАВЦЯ (під рядком своєї команди):   ПОЗИЦІЯ  Ім'я
#   Позиція: GK (воротар), DF (захисник), MF (півзахисник), FW (нападник).
#   Замість скорочення можна писати слово: воротар, захисник, півзахисник, нападник.
#   Ім'я може містити пробіли. Відступ перед позицією необов'язковий.
#
# ВИМОГИ:
#   - рівно 36 команд;
#   - у кожної команди рівно 11 гравців, з них рівно один воротар;
#   - імена гравців у межах команди не повторюються;
#   - перші 9 команд - корзина 1, наступні 9 - корзина 2 і так далі;
#   - номер команди в списку (1-36) є її початковим рейтингом
#     (використовується як 5-те правило сортування турнірної таблиці).
#
# ХТО ЗАБИВАЄ: нападники забивають найчастіше, потім півзахисники, потім захисники,
#   воротарі не забивають (див. SCORER_WEIGHT_* у core/Config.h).
#
# УВАГА: склади корзини 1 складено з пам'яті як приклад. Вони можуть бути неточними
#   (трансфери, травми, схеми) - перевірте й виправте. У решти команд стоять шаблонні
#   імена (Воротар, Захисник 1, ...) - замініть їх на справжні.
#
# Порожні рядки та рядки, що починаються з #, ігноруються.
# Файл можна зберігати в UTF-8 (з BOM або без) чи Windows-1251.
